# Assets

`stimuli.csv` contains the audited uppercase English word and pronounceable-nonword
pool used by the ongoing lexical-decision task. The four nonfocal PM targets
(`DOCTOR`, `FACTOR`, `PASTOR`, `TRACTOR`) and the focal target (`PACKET`) are
inserted by the deterministic block planner and intentionally excluded from the
filler pool.

`embedded_figures.svg` is an original line drawing that implements the reported
embedded-figures distractor class without copying proprietary historical test
materials. `embedded_figures.png` is the PsychoPy runtime rendering generated from
that SVG.
