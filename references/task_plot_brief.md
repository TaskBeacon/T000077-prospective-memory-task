# Task Plot Brief

Title: Prospective Memory Task
Construct: prospective memory / attentional monitoring

## Purpose

Show how the same ongoing lexical-decision task changes when a focal or nonfocal
prospective-memory intention is active.

## Participant-Visible Rows

1. Baseline: classify an uppercase word/nonword, then press SPACE on `WAITING`.
2. Focal target: classify `PACKET`, then press `/` on `WAITING`, then SPACE.
3. Nonfocal target: classify a word containing `TOR` such as `DOCTOR`, then press
   `/` on `WAITING`, then SPACE.

## Timing and Responses

- Letter string: up to 3 s; F = NONWORD, J = WORD.
- Waiting screen: up to 10 s.
- Baseline/nontarget advancement: SPACE.
- Target action: `/`, followed by SPACE.
- PM targets occur at trials 25, 50, 75, and 100 in each 105-trial PM block.

## Visual Facts

- Light-gray participant screen.
- Uppercase letter string centered in dark monospaced type.
- `WAITING` centered in gray.
- Do not highlight `TOR` within `DOCTOR`; participants see a uniform word.
- Do not show correctness feedback, scores, people, devices, or internal condition IDs.
- The plot should focus on a representative trial; the 120-s distractor belongs at
  block level and may be a small note, not a trial phase.
